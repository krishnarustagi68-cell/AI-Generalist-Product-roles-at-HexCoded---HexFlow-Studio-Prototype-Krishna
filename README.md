# HexFlow Studio: Agentic Node Director & Continuity Canvas
> **Built for HexCoded Creative Studio & AI Filmmaking Workflows**  
> Tailored for editors, commercial directors, filmmakers, and creative agencies.

---

## The Core Problem in Generative Video
Current generative AI tools for creative professionals are stuck in two extremes:
1. **Prompt-and-Pray Textboxes** (Runway, Sora, Pika): Lack shot consistency, camera optics, and repeatable scene continuity. Characters mutate from shot to shot.
2. **ComfyUI**: Immensely powerful, but terrifying UX. Spaghetti wires, python dependencies, and zero concept of cinematic storytelling.

## The Solution: HexFlow Studio
HexFlow unifies the control of modular nodes with the intuition of an AI Co-Director:
- **Modular Creative Rigs:** Nodes for Scene Storyboard, Character & Wardrobe Anchors (Face LoRA Lock), 35mm/85mm Anamorphic Optics, Kodak 500T Color Grading, Atmospheric Physics, and Magnific 4K Detail Relighting.
- **Agentic Co-Director Chat:** Natural language copilot that programmatically inspects, constructs, and reconfigures the node graph in real time.
- **Shot Continuity Matrix:** Multi-shot identity scoring (98.4% match), preventing face and wardrobe hallucination across sequential cuts.
- **Cinematic Timeline & 2.39:1 CinemaScope Player:** Multi-shot scrubber with audio waveforms and camera movement HUD overlays.
- **Production Interoperability:** One-click export to ComfyUI JSON, HexCoded API payloads, and printable Director Call Sheets.

## Quick Start

### 1. Install & Run Locally
```bash
# Clone or navigate to the project
cd hexcoded-creative-studio

# Install dependencies
npm install

# Start Vite dev server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Deploy to Vercel in 60 Seconds
```bash
# Deploy with Vercel CLI
npx vercel
```
Or push to GitHub and connect to [Vercel](https://vercel.com) / [Render](https://render.com).
